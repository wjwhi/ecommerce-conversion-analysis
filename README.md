# E-Commerce Conversion Analysis

## Business Question
What user behaviors and marketing factors are associated with conversion?

## Tools Used
- MySQL
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
Synthetic e-commerce dataset containing 100,000 website sessions.

## Key Findings
- Overall conversion rate was 49.75%.
- No single variable strongly predicted conversion on its own.
- Conversion appears to be influenced by a combination of factors.

## Visualizations
- Conversion count bar chart
- Correlation heatmap
- Time on site by conversion status
- Cart additions by conversion status
- Conversion rate by discount bucket

## Business Recommendation
Use multivariate analysis or machine learning to identify which combinations of features most influence conversion.
